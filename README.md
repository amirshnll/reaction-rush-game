# Reaction Rush

## Short description

Test how quickly you can react to a changing target.

## Description

Reaction Rush is a fast, accessible, multilingual reaction-time mini-game for the browser. It measures successful response times, tracks personal records and averages, and includes keyboard controls, sound settings, and local statistics.

## Purpose

The extension provides a simple way to practice reaction speed and focus through short, repeatable sessions launched from the browser toolbar.
